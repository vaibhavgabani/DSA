# Data Structures - Assignment 3

**BSc I.T. 3rd Semester, VNSGU**  
**Date: 3rd October 2024**

This repository contains solutions for Assignment 3, which focuses on implementing various types of linked lists and performing different operations in C. Each task addresses a specific aspect of linked list manipulation.

## Assignment Tasks

1. **Singly Linked List (with Sorting)**  
   - Implement all operations on a singly linked list, including insertion, deletion, searching, and sorting.

2. **Circular Singly Linked List**  
   - Write a program to implement all operations on a circular singly linked list.

3. **Queue Implementation using Linked List**  
   - Implement a queue data structure using a linked list.

4. **Stack Implementation using Linked List**  
   - Implement a stack data structure using a linked list.

5. **Doubly Linked List with Full Operations**  
   - Perform all operations on a doubly linked list, including:
     - Display from first to last.
     - Display from last to first.

6. **Linked List for Student Data**  
   - Implement a linked list to store student data with the following fields:
     - Roll number, Name, Semester, Subject 1 Marks, Subject 2 Marks, Subject 3 Marks, Total Marks.
   - Perform the following operations:
     - Insertion
     - Display
     - Delete by roll number
     - Display the student node with the highest marks

7. **Merging of Two Linked Lists**  
   - Create two linked lists that contain two values in each node: a character and an integer.
   - Divide the list into two separate linked lists: one for integers and one for characters.
   - Perform addition of all integer values in the singly linked list.

8. **Singly Linked List for Polynomial Representation**  
   - Create a singly linked list to represent a polynomial expression.

9. **Sum of Node Values in Singly Linked List**  
   - Create a singly linked list and perform the sum of all node values.
